v1.0.0 OAS 3.0 • {{ baseUrls.citas }} • {{ baseUrls.pacientes }} • {{ baseUrls.recetas }} • {{ baseUrls.reportes }} • {{ baseUrls.notificaciones }}
Servidor Activo: Localhost (ASP.NET Core 9 + Angular 20)

Interfaz interactiva estilo Swagger UI para los microservicios de Pacientes, Citas, Recetas, Reportes/Dashboard y Notificaciones (Worker Service). Ingresa parámetros, ejecuta peticiones HTTP y visualiza el código de estado y la respuesta en tiempo real. El flujo clínico de una cita evoluciona el mismo CitaID mediante PUT: registro de atención secuencial, reprogramación en PendienteResultados y emisión de receta en Concluida.
