MedicalAppointments.Api & Worker Services

v1.0.0 OAS 3.0 • http://localhost:5000 • http://localhost:5100
Servidor Activo: Localhost (ASP.NET Core 9 + Angular 20)

Esta interfaz web implementa de forma interactiva todas las funciones expuestas en Swagger UI para los microservicios de Citas, Estados y Notificaciones (Worker Service). Puedes ingresar parámetros, ejecutar peticiones HTTP directas y visualizar el código de estado y cuerpo de respuesta en tiempo real.
